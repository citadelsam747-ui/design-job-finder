ДизайнРабота — мобильная PWA-заготовка

Важно:
- Исходный job_finder.py использовал Tkinter и предназначался для компьютера; напрямую на Android он не запускается.
- Эта версия — мобильное веб-приложение, которое можно опубликовать с телефона через GitHub Pages и добавить на главный экран Android.
- Кнопки открывают реальные внешние сайты с поисковыми запросами; приложение не собирает все вакансии в одну базу и не подтверждает зарплату/актуальность.
- Сохранённые вакансии и настройки остаются в хранилище браузера на этом устройстве.

Публикация с телефона:
1. В браузере открой https://github.com и войди/создай аккаунт.
2. Нажми + → New repository. Название: design-job-finder. Выбери Public и Create repository.
3. Нажми Add file → Upload files и загрузи index.html, manifest.webmanifest и sw.js из этого ZIP.
4. Нажми Commit changes.
5. Открой Settings → Pages. В разделе Build and deployment выбери Deploy from a branch; Branch: main, folder: /(root), Save.
6. Подожди публикации, затем открой показанный GitHub Pages URL на телефоне.
7. В Chrome нажми ⋮ → «Добавить на главный экран» или «Установить приложение» (название пункта зависит от версии браузера).
